# PatternPilot — Dashboard API Requirements

> Generated by scanning every page and component in `/dashboard`.  
> All existing auth APIs (login, register, forgot-password, refresh-token) are **already integrated** and excluded from this document.

---

## 🏗️ Architecture Decision: Python vs Node.js

| Layer                                                                       | Runtime                          | Reason                                                                                              |
| --------------------------------------------------------------------------- | -------------------------------- | --------------------------------------------------------------------------------------------------- |
| **Auth, Users, Portfolio CRUD, Alerts, Settings**                           | **Node.js (Express/Fastify)**    | Fast I/O, JSON heavy, already using Node backend                                                    |
| **AI Predictions, Market Signals, Candlestick/OHLCV data, Stock screening** | **Python (FastAPI)**             | NumPy/Pandas for data crunching, scikit-learn/LLMs for predictions, yfinance/Alpha Vantage wrappers |
| **Real-time price streaming**                                               | **Python (FastAPI + WebSocket)** | asyncio WebSocket streaming from market data providers                                              |

## 🔴 Real-time APIs (WebSocket)

These need to be handled by the **Python FastAPI** service with `asyncio` WebSocket support.

### `WS /ws/prices?symbols=AAPL,GOOGL,MSFT`

Streams live price ticks for subscribed symbols. Used to keep the stocks table and header price refreshed.

```json
// Message pushed by server every ~5s
{
    "type": "price_update",
    "data": {
        "AAPL": { "price": 183.1, "change": 0.58, "changePercent": 0.32 },
        "GOOGL": { "price": 143.2, "change": 0.82, "changePercent": 0.57 }
    }
}
```

---

### `WS /ws/alerts`

Streams new alerts in real-time. Used to update the bell badge and alerts page without polling.

```json
// Message pushed when a new alert fires
{
    "type": "new_alert",
    "data": {
        "id": "uuid",
        "type": "price",
        "stock": "TSLA",
        "title": "Price Alert Triggered",
        "message": "Tesla hit your target of $250.00",
        "read": false,
        "createdAt": "2024-04-17T12:34:00Z"
    }
}
```

## 🔑 API Priority Order (Build This First)

### Phase 1 — Core (unblock hardcoded UI)

1. `GET /api/users/me` — show real user name/email in header & profile
2. `GET /api/portfolio/stocks` + `POST` — replace hardcoded stocks table
3. `GET /api/portfolio/summary` — replace hardcoded stat cards
4. `GET /api/portfolio/performance` — replace generated chart with real data
5. `GET /api/alerts` + `GET /api/alerts/stats` — real notification system

### Phase 2 — AI Core

6. `GET /api/ai/predictions` — most valuable feature
7. `GET /api/ai/market-signals`
8. `GET /api/ai/analysis-summary`
9. `POST /api/ai/predictions/refresh`
